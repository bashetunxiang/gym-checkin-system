# Gym Checkin System

一个基于 Flask、OpenCV 和原生 Web 技术构建的体育馆视频打卡管理系统，覆盖账号管理、人员管理、人脸识别打卡、在馆状态追踪和数据分析。

项目同时提供网页管理后台（`app.py`）和命令行入口（`main.py`），适合本地开发、课程设计与功能演示。

## 功能概览

### 账号与安全

- 自助注册账号，自动检测重复账号
- 注册成功后生成随机初始密码
- 首次登录自动引导修改密码
- 登录状态下修改当前密码
- 忘记密码时使用初始密码验证并设置新密码
- 当前密码和初始密码均采用哈希形式保存
- 兼容旧版账号数据并在首次使用时自动迁移

### 场馆管理

- 添加和更新人员资料
- 记录人员入馆、离馆时间及停留时长
- 显示人员进入场馆的先后顺序
- 查询当前在馆人员和全部历史记录
- 支持手动进入/离开打卡

### 视频与人脸识别

- 浏览器实时摄像头画面
- OpenCV 人脸检测
- 采集人员人脸样本
- 训练 LBPH 人脸识别模型
- 单次识别打卡与循环自动打卡
- 自动入馆和自动离馆模式

### 统计与界面

- 今日到馆人数、当前在馆人数、今日离馆人数
- 平均停留时间、近 7 日到馆趋势和月度统计
- 响应式深色管理后台，适配桌面和手机
- 不同功能页面拥有独立强调色
- 顶部使用 24 小时时钟显示本地日期与时间
- 太阳和月亮根据时间东升西落，天空在清晨、白天、黄昏和夜间自动切换

## 技术栈

- Python 3.10+
- Flask
- OpenCV Contrib
- NumPy
- Jinja2
- HTML、CSS、JavaScript
- ECharts（通过 CDN 加载）

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/bashetunxiang/gym-checkin-system.git
cd gym-checkin-system
```

### 2. 创建 Python 环境

推荐使用 Miniconda：

```bash
conda create -n gym-checkin python=3.12 -y
conda activate gym-checkin
```

也可以使用 Python 自带的虚拟环境：

```bash
python -m venv .venv
```

Windows PowerShell 激活命令：

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 4. 启动网页版本

```bash
python app.py
```

浏览器访问：

```text
http://127.0.0.1:5000
```

默认演示账号：

```text
账号：dhl
密码：541610
```

> 默认账号仅用于本地演示。首次启动后建议立即在“系统设置”中修改密码。

### 5. 启动命令行版本

```bash
python main.py
```

## 账号使用流程

### 注册

1. 在登录页选择“注册新账号”。
2. 输入 3–32 位账号，可使用字母、数字、点、短横线或下划线。
3. 系统生成并展示初始密码。
4. 保存初始密码并使用它完成首次登录。
5. 系统自动进入“系统设置”，完成密码修改。

### 忘记密码

1. 在登录页选择“忘记密码”。
2. 输入账号、注册时保存的初始密码和新密码。
3. 验证通过后使用新密码登录。

初始密码不会再次显示，请将其保存在安全的位置。

## 人脸自动打卡流程

1. 在“人员管理”中添加人员编号和姓名。
2. 进入“视频打卡”页面，确认摄像头画面可用。
3. 输入人员编号并采集多张人脸样本。
4. 点击“训练识别模型”。
5. 选择自动入馆或自动离馆模式。
6. 执行单次识别，或开启循环自动打卡。

运行时生成的人脸样本、识别模型和标签文件不会提交到 Git 仓库。

## 数据文件

本地数据保存在 `data/` 目录：

| 文件 | 用途 |
| --- | --- |
| `user_password.txt` | 账号及密码哈希 |
| `personnel.txt` | 人员资料 |
| `lock_record.txt` | 入馆和离馆记录 |
| `faces/` | 人脸训练样本（运行时生成） |
| `face_model.yml` | LBPH 识别模型（运行时生成） |
| `face_labels.json` | 人脸标签映射（运行时生成） |

请勿将真实账号、人员资料、人脸样本或场馆记录提交到公开仓库。

## 使用说明

- 项目默认监听 `127.0.0.1:5000`，仅供本机访问。
- 如需固定登录会话，可通过 `GYM_CHECKIN_SECRET_KEY` 环境变量配置 Flask 会话密钥。
- 摄像头功能需要系统授予相机访问权限。
- ECharts 通过 CDN 加载；离线时页面仍可使用，但图表区域可能无法显示。
- 本项目当前定位为本地演示系统。用于生产环境前，请配置独立密钥、HTTPS、数据库、权限控制、审计日志和可靠的账号恢复机制。
