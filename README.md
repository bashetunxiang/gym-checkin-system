# Gym Checkin System

一个基于 Flask、OpenCV 和原生 Web 技术构建的体育馆视频打卡管理系统，覆盖账号管理、人员管理、人脸识别打卡、在馆状态追踪和数据分析。

项目同时提供网页管理后台（`app.py`）和命令行入口（`main.py`），适合本地开发、课程设计与功能演示。

## 功能概览

### 账号与安全

- 自助注册账号，自动检测重复账号
- 新注册账号统一分配初始密码 `88888888`
- 首次登录自动引导修改密码
- 登录状态下修改当前密码
- 忘记密码时使用初始密码验证并设置新密码
- 当前密码和初始密码均采用哈希形式保存
- 兼容旧版账号数据并在首次使用时自动迁移

### 场馆管理

- 添加和更新人员资料
- 记录人员入馆、离馆时间及停留时长
- 显示人员进入场馆的先后顺序
- 查询当前在馆人员和全部历史记录
- 支持手动进入/离开打卡

### 视频与人脸识别

- 浏览器实时摄像头画面
- OpenCV 人脸检测
- 采集人员人脸样本
- 训练 LBPH 人脸识别模型
- 单次识别打卡与循环自动打卡
- 自动入馆和自动离馆模式
- 登录首页提供独立的入馆扫脸终端和离馆扫脸终端，无需管理账号即可打卡

### 统计与界面

- 今日到馆人数、当前在馆人数、今日离馆人数
- 平均停留时间、近 7 日到馆趋势和月度统计
- 响应式深色管理后台，适配桌面和手机
- 不同功能页面拥有独立强调色
- 顶部使用 24 小时时钟显示本地日期与时间
- 中央大屏登录管理后台后实时刷新当前在馆人员和今日统计
- 太阳和月亮根据时间东升西落，天空在清晨、白天、黄昏和夜间自动切换

## 技术栈

- Python 3.10+
- Flask

- NumPy
- Jinja2
- HTML、CSS、JavaScript
- ECharts（通过 CDN 加载）

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/bashetunxiang/gym-checkin-system.git
cd gym-checkin-system
```

### 2. 创建 Python 环境

推荐使用 Miniconda：

```bash
conda create -n gym-checkin python=3.12 -y
conda activate gym-checkin
```

也可以使用 Python 自带的虚拟环境：

```bash
python -m venv .venv
```

Windows PowerShell 激活命令：

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. 安装依赖

```bash
python -m pip install -r requirements.txt
```

### 4. 启动网页版本

```bash
python app.py
```

浏览器访问：

```text
http://127.0.0.1:5000
```

默认演示账号：

```text
账号：dhl
密码：541610
```

> 默认账号仅用于本地演示。首次启动后建议立即在“系统设置”中修改密码。

### 5. 启动命令行版本

```bash
python main.py
```

## 账号使用流程

### 注册

1. 在登录页选择“注册新账号”。
2. 输入 3–32 位账号，可使用字母、数字、点、短横线或下划线。
3. 系统分配并展示统一初始密码 `88888888`。
4. 保存初始密码并使用它完成首次登录。
5. 系统自动进入“系统设置”，完成密码修改。

### 忘记密码

1. 在登录页选择“忘记密码”。
2. 输入账号、注册时保存的初始密码和新密码。
3. 验证通过后使用新密码登录。

新注册账号的初始密码统一为 `88888888`，首次登录后请立即修改；找回密码时也可使用该初始密码验证身份。

## 人脸自动打卡流程

1. 在“人员管理”中添加人员编号和姓名。
2. 进入“视频打卡”页面，确认摄像头画面可用。
3. 输入人员编号并采集多张人脸样本。
4. 点击“训练识别模型”。
5. 入口设备打开登录首页中间的“进入场馆”，识别人脸后写入到馆时间。
6. 出口设备打开登录首页右侧的“离开场馆”，识别人脸后写入离馆时间并计算停留时长。
7. 场馆中央大屏通过左侧“进入系统”登录，展示当前在馆人员和统计数据。

入口、出口与中央大屏对应的页面互相独立。扫脸终端只更新人员到馆记录，不会创建管理账号登录会话。

运行时生成的人脸样本、识别模型和标签文件不会提交到 Git 仓库。

## 三端页面与部署

| 使用位置 | 页面入口 | 是否需要管理账号 | 主要作用 |
| --- | --- | --- | --- |
| 场馆中央大屏 | `/login` 登录后进入 `/dashboard` | 是 | 展示当前在馆人员、今日在馆时间、在馆总时长、今日统计和近 7 日趋势 |
| 场馆入口设备 | `/face-checkin/enter` | 否 | 识别人脸并记录到馆时间，防止重复入馆 |
| 场馆出口设备 | `/face-checkin/leave` | 否 | 识别人脸并记录离馆时间，自动计算停留时长 |

当前版本通过运行 Flask 的电脑读取本机 `0` 号摄像头。用于真实场馆的三台独立设备时，可在每台设备上分别运行本项目并打开对应页面；若需要多设备共同使用同一份实时数据，建议将文本文件存储升级为中心数据库，并让各终端连接同一个后端服务。

打开扫脸终端后，页面会同时显示 OpenCV 安装状态和摄像头状态。若提示 OpenCV 已安装但无法打开摄像头，请关闭其他占用相机的程序，并在 Windows“隐私和安全性 → 相机”中允许桌面应用访问摄像头。

## 数据文件

本地数据保存在 `data/` 目录：

| 文件 | 用途 |
| --- | --- |
| `user_password.txt` | 账号及密码哈希 |
| `personnel.txt` | 人员资料 |
| `lock_record.txt` | 入馆和离馆记录 |
| `faces/` | 人脸训练样本（运行时生成） |
| `face_model.yml` | LBPH 识别模型（运行时生成） |
| `face_labels.json` | 人脸标签映射（运行时生成） |

请勿将真实账号、人员资料、人脸样本或场馆记录提交到公开仓库。

## 使用说明

- 项目默认监听 `127.0.0.1:5000`，仅供本机访问。
- 如需固定登录会话，可通过 `GYM_CHECKIN_SECRET_KEY` 环境变量配置 Flask 会话密钥。
- 摄像头功能需要系统授予相机访问权限。
- ECharts 通过 CDN 加载；离线时页面仍可使用，但图表区域可能无法显示。
- 本项目当前定位为本地演示系统。用于生产环境前，请配置独立密钥、HTTPS、数据库、权限控制、审计日志和可靠的账号恢复机制。
