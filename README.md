# 体育馆视频打卡管理系统

这是一个基于 Python、OpenCV 和 Flask 的体育馆视频打卡管理系统，保留控制台入口 `main.py`，并新增网页入口 `app.py`。

## 功能

- 人员进入场馆、离开场馆
- 记录第几个进入场馆、进入时间、离馆时间和停留时间
- 查询当前在馆人员和全部到馆记录
- 统计今日到馆人数、当前在馆人数、今日离馆人数、平均停留时间
- 日报：查看今天在馆时长
- 月报：查看本月在馆时长
- 网页端视频打卡、人脸采集、模型训练和自动识别打卡

## 运行控制台版本

```bash
python main.py
```

## 运行网页版本

## 人脸自动打卡

网页端进入“视频打卡”页面后，先在人员管理中添加人员，再采集该人员的人脸样本并训练识别模型。训练完成后可开启自动人脸打卡。

运行时生成的人脸样本和训练模型不会提交到仓库。
